# Maya session archive

Архив невидеоэкранов Sessions 1–12, разделов Learn, Practice, Review и Homework.

- `STATUS.txt` — состояние архива и итоговое количество изображений.
- `screenshots.json` — опись скриншотов.
- `inventory.json` — перечень файлов.
- `Видео/` — отдельные полные видеозаписи модулей.

Видео именуются по схеме `Session N — раздел — название видео.mov`.
